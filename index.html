3

Backend และสมาชิก

สร้าง Supabase Project

  1. 1
    สร้าง Project

    เข้า supabase.com กด New project เลือก region Singapore และตั้ง Database Password

  2. 2
    สร้างตาราง

    เปิด SQL Editor → New query แล้วคัดลอกไฟล์ db/schema.sql ทั้งไฟล์ไป Run

  3. 3
    ตั้งค่า Login

    Authentication → Providers → Email ช่วงพัฒนาปิด Confirm email ได้ แต่ production ควรเปิดพร้อม Custom SMTP

  4. 4
    ตั้ง URL

    Authentication → URL Configuration เพิ่ม http://localhost:8765/** และ URL production

  5. 5
    คัดลอก API settings

    Project Settings → API เก็บ Project URL และ publishable/anon key

shopsingredientssub_recipessub_recipe_itemsproductsproduct_itemschannelscategoriespricing
ห้ามใส่ secret key ในหน้าเว็บใช้เฉพาะ publishable/anon key เท่านั้น ความปลอดภัยของข้อมูลมาจาก RLS
4

เชื่อมต่อระบบ

ตั้งค่า web/config.js

นำ Project URL และ publishable key ของ Supabase มาแทนค่าตัวอย่าง

web/config.js
export const SUPABASE_URL =
  'https://XXXXXXXX.supabase.co';

export const SUPABASE_ANON_KEY =
  'sb_publishable_XXXXXXXX';
ติดตั้งให้ลูกค้าใหม่ต้องเปลี่ยน URL และ key เป็น Supabase ของลูกค้าทุกครั้ง เพื่อไม่ให้ข้อมูลปนกัน

รูปภาพ — เลือกทำได้

ตั้งค่า Cloudinary

  1. สมัครบัญชีที่ cloudinary.com
  2. Settings → Upload → Upload presets
  3. สร้าง preset แบบ Unsigned
  4. คัดลอก Cloud name และ Upload preset ลง `web/config.js`
web/config.js
export const CLOUDINARY = {
  cloudName: 'YOUR_CLOUD_NAME',
  uploadPreset: 'YOUR_UNSIGNED_PRESET',
};

ไม่ตั้งค่าก็ใช้งานได้ ระบบจะแสดง emoji แทนรูป

Production

นำเว็บขึ้น GitHub Pages

Deploy เฉพาะโฟลเดอร์ web/
git add .
git commit -m "Deploy EpicMargin"
git push origin main
git subtree push --prefix web origin gh-pages
  1. GitHub repository → Settings → Pages
  2. Source = Deploy from a branch
  3. Branch = gh-pages และ folder = /(root)
  4. นำ URL ที่ได้กลับไปใส่ Supabase Site URL และ Redirect URLs

Troubleshooting

แก้ปัญหาที่พบบ่อย

เปิดแล้วเป็นหน้าขาว

อย่าเปิด `index.html` โดยตรง ให้รัน `node scripts/serve-web.mjs` และเปิด `http://localhost:8765`

ล็อกอินได้แต่แอปโหลดไม่ครบ

รัน `db/schema.sql` รุ่นล่าสุดอีกครั้ง ต้องมีครบ 9 ตาราง โดยเฉพาะ `categories` และ RLS policy

ขึ้น Failed to fetch

ตรวจ Project URL, publishable key, อินเทอร์เน็ต และ Network tab ใน Developer Tools

สมัครแล้วเข้าไม่ได้

ถ้าเปิด Confirm email ต้องยืนยันอีเมลก่อน ตรวจ Spam และการตั้งค่า SMTP

ขึ้น row-level security policy

ตรวจว่าผู้ใช้ล็อกอินแล้ว และรัน schema ที่มี RLS policy ครบทุกตาราง

อัปโหลดรูปไม่ได้

ตรวจ Cloud name และ Upload preset โดย preset ต้องเป็น Unsigned
