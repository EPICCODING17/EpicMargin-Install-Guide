# EpicMargin Installation Guide

เว็บไซต์คู่มือติดตั้ง EpicMargin ตั้งแต่เตรียมเครื่อง สร้าง Supabase ตั้งค่า Cloudinary ทดสอบระบบ จนถึงการนำขึ้นใช้งานจริง

เปิดเว็บไซต์: https://epiccoding17.github.io/EpicMargin-Install-Guide/

## เนื้อหา

- คู่มือภาษาไทยแบบทีละขั้นตอน
- ภาพหน้าจอระบบจริง
- คำสั่ง PowerShell พร้อมปุ่มคัดลอก
- เช็กลิสต์ก่อนส่งมอบ
- รองรับมือถือ โหมดมืด และการบันทึกเป็น PDF
